# Small Screen Status 安装与使用

这是供手机大小副屏使用的 macOS 任务状态窗口。应用显示本机 Codex 任务、脚本进度和提醒，也有计时、笔记、清单和时钟。它不监测浏览器中的 ChatGPT 对话。

## 安装

支持 macOS 13+、Apple Silicon 与 Intel。监测和脚本功能需要 Python 3.9+；默认使用 Apple Command Line Tools 提供的 `/usr/bin/python3`。若系统尚无该工具，先运行 `xcode-select --install`，按 Apple 提示完成后再安装。

解压应用 ZIP，双击 `install.command`。安装程序将应用放在 `~/Applications/Small Screen Status.app`，设置随本机 ChatGPT/Codex 启动和退出，并安装三个配套 agent skill。整个过程无需 sudo；安装完可删除下载目录。已有同名 skill 会保留，更新应用时也保留用户配置与内容。

也可在解压目录运行：

```sh
python3 install.py --dry-run          # 查看计划并验证包，不安装
python3 install.py                    # 安装并设置启停联动
python3 install.py --check            # 检查已安装应用和监听器
python3 install.py --remove-autostart # 取消启停联动
```

若已有其他 Python 3.9+，使用 `--python /absolute/path/to/python3`。`--app-dir` 可指定安装目录，`--host-app` 可指定 ChatGPT/Codex 应用，`--no-autostart` 可跳过联动。独立的 `small-screen-install` skill ZIP 包含应用包：解压到 agent 的 skills 目录后，可让 agent 用 `$small-screen-install` 安装。

应用使用临时签名，未经过 Apple 公证。首次打开若被 macOS 阻止，请在“系统设置 → 隐私与安全性”找到该应用并选择“仍要打开”，按系统提示确认。参见 [Apple 官方说明](https://support.apple.com/102445)。

## 日常使用

从主屏菜单栏 `◉ → 选择显示屏` 选小屏。默认自动选面积最小的副屏；只有主屏时保持隐藏。菜单也可显示或隐藏窗口、调整字号和退出。应用不显示 Dock 图标。

点击任务打开原对话，点击顶部编号可固定监测 5 分钟。`⌃⌥⌘ + 1–9` 跳转对应位置，`⌃⌥⌘⇧ + 1–9` 固定监测，`⌃⌥⌘ + 0` 返回总览，`⌃⌥⌘ + T` 切换任务、待处理和工具页。计时在应用关闭期间仍按实际时间流逝，再打开会恢复。

已有 Codex 内置提问可在小屏准备回复，然后复制并跳转原对话提交。新提问若由 `$small-screen-ask` 发起，可在小屏直接提交并返回等待中的任务。正式权限审批须在原应用完成。用 `$small-screen-tools` 可添加本地工具；应用内的 `Contents/Resources/EXTENSIONS.md` 说明配置格式。

个人内容保存在 `~/Library/Application Support/SmallScreenStatus/`。安装程序的 `--check` 可查看运行状态；这个目录的日志和状态文件可能含个人任务信息，分享或报错前请检查。分享包内的 `manifest.json` 用于验证内容完整性，外部 `SHA256SUMS.txt` 用于核对下载的 ZIP。
