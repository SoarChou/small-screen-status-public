# 使用指南

## 选择显示屏

启动后从主屏菜单栏 `◉ → 选择显示屏` 指定目标。自动模式选择面积最小的副屏；只有主屏时隐藏窗口。显式选择的显示屏断开后，窗口会隐藏。菜单也可调整字号或退出；点击窗口后用 `+` / `-` 调整字号、`Esc` 隐藏。

安装程序可配置随本机 ChatGPT/Codex 启动和退出。手动退出小屏后，会等宿主下一次启动才自动打开。浏览器里的 ChatGPT 对话没有本地 Codex 任务记录，但工具页仍可使用。

## 任务和提醒

任务页显示最近 24 小时更新过的未归档 Codex 聊天，以及仍在运行的任务。名称优先使用 Codex 侧栏当前标题；摘要只取公开进展。运行任务位置保持稳定，已结束任务保留数分钟。总览一次显示至多三行，任务较多时自动翻页；顶部任务条可选择任意位置并固定监测 5 分钟。

| 操作 | 结果 |
| --- | --- |
| 点击任务标题或 ↗ | 打开原对话；脚本任务打开本地状态记录 |
| 点击顶部任务编号 | 固定监测该任务 5 分钟 |
| `⌃⌥⌘ + 1–9` | 打开顶部对应位置的任务 |
| `⌃⌥⌘⇧ + 1–9` | 固定监测顶部对应位置的任务 |
| `⌃⌥⌘ + 0` | 返回总览 |
| `⌃⌥⌘ + T` | 切换任务、待处理、工具页 |

运行中的任务完成、失败或中断，以及计时结束、新提问到达时会弹出提示；可以提前关闭。任务完成指当前一轮结束，不等于整个长期项目结束。权限提示提供返回原对话的入口，实际授权须在原应用完成。

## 提问和回复

待处理页展示本机记录中明确发出的提问及选项。对已有 Codex 内置提问，小屏可准备回复、复制到剪贴板并打开原对话；仍须在原对话提交。追加指令也使用该流程。

若当前任务使用随包提供的 `$small-screen-ask` skill 发起新提问，用户可在小屏点选或输入后直接提交，答案会返回等待中的任务。多题需填齐后提交；超时或取消不视作回答。这个路径不承接正式权限审批。

## 工具与脚本进度

工具页默认提供 5/25/50 分钟计时、笔记、清单和本地/UTC 时钟。计时按截止时间计算；关闭应用期间时间仍流逝，再启动可恢复。工具配置在 `~/Library/Application Support/SmallScreenStatus/widgets.json`，可用 `$small-screen-tools` 或 `src/cli/widgetctl.py` 添加现有类型；格式见 [扩展协议](EXTENSIONS.md)。

要把脚本显示在任务页，从仓库根目录运行：

```sh
python3 src/cli/screenctl.py run --title '构建项目' -- npm run build
```

被包装的脚本继承 `SMALL_SCREEN_TASK_ID`，可主动报告真实进度：

```sh
python3 src/cli/screenctl.py progress 40 --message '完成 40%'
```

脚本状态写入本机应用支持目录；标准输出仍留在终端，退出码原样返回。应用退出不会停止外部脚本。
