# 使用指南

## 选择显示屏

启动后从主屏菜单栏的叠屏图标打开“选择显示屏”指定目标。自动模式选择面积最小的副屏；只有主屏时隐藏窗口。显式选择的显示屏断开后，窗口会隐藏。菜单中的“显示小屏窗口”或重新打开应用可再次显示窗口。菜单也可调整字号或退出；点击窗口后用 `+` / `-` 调整字号、`Esc` 隐藏。

安装后小屏作为独立应用在登录 Mac 时自动启动。手动退出后，本次登录期间不会被 ChatGPT/Codex 重新打开；下次登录时会再次启动。浏览器里的 ChatGPT 对话没有本地 Codex 任务记录，但工具页仍可使用。

## 任务和提醒

任务页显示最近 24 小时更新过的未归档 Codex 聊天，以及仍在运行的任务。名称优先使用 Codex 侧栏当前标题；摘要只取公开进展。安装并运行 `dsh-small-screen-status` 插件时，也会显示 DSH 会话。运行任务位置保持稳定，已结束任务保留数分钟。总览一次显示至多两行；顶部可手动按来源查看。总览超过一页时每 20 秒平滑翻页；所有任务都放得下时保持总览。点击分页点或分组会暂停轮换 60 秒，鼠标悬停和系统“减少动态效果”也会暂停。顶部任务条可固定监测 5 分钟。

任务页右上角的“来源”按钮打开大尺寸选项，可选择显示 Codex、DSH、脚本中的哪些任务。选择会保存在这台 Mac 上，至少保留一个来源；隐藏的来源不会占用任务位置快捷键。

| 操作 | 结果 |
| --- | --- |
| 点击任务标题或 ↗ | 打开 Codex 或 DSH 原对话；脚本任务打开本地状态记录 |
| 点击顶部任务编号 | 固定监测该任务 5 分钟 |
| `⌃⌥⌘ + 1–9` | 打开顶部对应位置的任务 |
| `⌃⌥⌘⇧ + 1–9` | 固定监测顶部对应位置的任务 |
| `⌃⌥⌘ + 0` | 返回总览 |
| `⌃⌥⌘ + T` | 切换任务、待处理、工具页 |

运行中的任务完成、失败或中断，以及计时结束、新提问到达时会弹出提示；可以提前关闭。任务完成指当前一轮结束，不等于整个长期项目结束。权限提示提供返回原对话的入口，实际授权须在原应用完成。

## 提问和回复

待处理页展示本机记录中明确发出的提问及选项。对已有 Codex 内置提问，小屏可准备回复、复制到剪贴板并打开原对话；仍须在原对话提交。追加指令也使用该流程。

若当前任务使用随包提供的 `$small-screen-ask` skill 发起新提问，用户可在小屏点选或输入后直接提交，答案会返回等待中的任务。多题需填齐后提交；超时或取消不视作回答。这个路径不承接正式权限审批。

## 工具与脚本进度

工具页默认提供 5/25/50 分钟计时、笔记、清单和本地/UTC 时钟。计时按截止时间计算；关闭应用期间时间仍流逝，再启动可恢复。工具配置在 `~/Library/Application Support/SmallScreenStatus/widgets.json`，可用 `$small-screen-tools` 或 `src/cli/widgetctl.py` 添加现有类型；格式见 [扩展协议](EXTENSIONS.md)。

要把脚本显示在任务页，从仓库根目录运行：

```sh
python3 src/cli/screenctl.py run --title '构建项目' -- npm run build
```

被包装的脚本继承 `SMALL_SCREEN_TASK_ID`，可主动报告真实进度：

```sh
python3 src/cli/screenctl.py progress 40 --message '完成 40%'
```

脚本状态写入本机应用支持目录；标准输出仍留在终端，退出码原样返回。应用退出不会停止外部脚本。

## 快捷操作区（1.4 试用版）

任务页底部“记一句”打开随手记，草稿自动保存在本机，“存下这句”记录时间和所选任务。只有一个任务或固定监测时默认关联它，多任务总览需自行选择。返回或 Esc 收起面板。

“稍后”先选择任务，再选 5 / 15 / 30 分钟后或完成时提醒；重新设置同任务同类型提醒会替换旧预约。列表可取消，到期使用小屏弹层，支持再过 5 分钟。提醒仅在小屏运行时显示，退出期间到期的预约会在下次启动时提示；未运行期间的任务完成记录取决于监测器能否再次读到该任务。

“产物”保留小屏运行期间观察到的新完成任务，不重放历史记录。没有上报路径时提供对话或任务记录入口与手动关联文件，不扫描工作目录。脚本可明确上报多个输出路径，文件尚未生成时也可指定：

```sh
python3 src/cli/screenctl.py run --title '分析任务' --artifact /absolute/path/report.pdf --artifact /absolute/path/figures -- python3 analysis.py
```

常用文档和图片按默认应用打开，目录及其他类型在访达定位。文件不存在时提示重新关联。笔记、收件箱、已看标记和提醒存入 `workbench.json`，任务离开总览后仍保留。

菜单栏叠屏图标 →“使用旧版工具栏”恢复原工具摘要。工具页的计时、笔记和清单继续使用原配置与数据。

### 快捷呼出与番茄钟

番茄钟常驻新版底部，未开始时点击旁边的播放按钮开始 25 分钟，运行中可暂停，暂停后可继续；点击“番茄钟”或剩余时间展开完整设置。

| 全局快捷键 | 功能 |
| --- | --- |
| `⌃⌥⌘N` | 随手记，直接聚焦输入 |
| `⌃⌥⌘P` | 番茄钟 |
| `⌃⌥⌘R` | 完成产物 |
| `⌃⌥⌘B` | 稍后提醒 |

随手记内 `⌘↩` 保存并返回，Esc 关闭面板并保留草稿。菜单栏叠屏图标也提供这四个入口。快捷操作只在主动呼出笔记时获取键盘焦点，自动提醒沿用原有行为；有紧急提示时先处理或关闭提示。24 个全局热键均注册成功时，诊断文件的 `registeredHotkeys` 为 24。旧的数字跳转、固定和切页快捷键保持不变。

界面按小屏近距离操作调整：按钮统一加大字号与点击区域，任务卡片每页两条；关联任务用整行大按钮选择，来源用独立面板选择。提问和工具长内容可滚动，菜单栏的字号增减仍可进一步调整。

## 设置窗口

小屏右上角齿轮、菜单栏“设置…”或应用内 `⌘,` 打开主屏上的独立设置窗口。小屏未连接时也可从菜单栏打开。

- 显示位置：自动选择最小副屏，或明确指定一块显示屏（含主屏）。选中的屏幕断开后隐藏任务窗口，重新连接时恢复。
- 窗口模式：铺满显示屏，或保持横向比例的窗口；窗口可居中或放在四角，大小滑块按屏幕宽度调整，并限制在可用区域内。
- 启动：开启或关闭“登录 Mac 后自动启动”，实际读取当前用户 LaunchAgent 注册状态。开启独立启动会替换指向本安装的旧 ChatGPT/Codex 跟随启动项；关闭不退出正在运行的应用。
- 外观：调整字号，或切回旧版工具栏。位置和外观设置立即应用并保存在本机。

设置页只管理指向当前安装的启动项，不需要管理员权限。若检测到其他安装占用同名启动项会提示错误；系统禁用背景登录项时可在系统设置中检查。应用移动位置后，应重新开启登录自启以使用新路径。
